# 投资与撤资概览

在 TTSWAP 这间链上商场里，**供货商（LP）** 给货架补货、再按规则撤货，是流动性的核心循环。与传统 DEX「必须准备两种等值资产开 pair」不同，TTSWAP 允许**只用一种商品补货**，撤货时再按凭证上的**历史进货数量**按比例返还——这是协议级「零无常损失」的基础。

## 你能做什么

| 动作 | 函数 | 说明 |
|:--|:--|:--|
| **开新货架** | `initGood` | 第一次为某种 Token 上架，自定初始价，获得品牌方身份 |
| **单币补货** | `investGood` | 给已有货架追加存货，获得 / 累加供货凭证 |
| **撤货结账** | `disinvestProof` | 按历史数量取回本金，并结算利润与 TTS 挖矿收益 |

## 核心概念速览

### 供货凭证（Proof）

每次补货，商场会记一张**供货凭证**，绑定「你 + 这条货架」：

- 记录你占多少货权份额（`shares`）、历史进货数量、折算价值等；
- `proofid = keccak256(owner, goodid)`，**同一人同一货架只有一张凭证**，多次补货会累加；
- 凭证**不是可二次交易的 NFT**，而是链上账本条目。

### 单币补货

调用 `investGood` 时，协议一律按货架**当前价 `V/Q`** 自动计价；单次补货折算价值须达到最小门槛。承诺型（`isPromised`）货架上的补货，还会同步记入 TTS 算力。

### 零无常损失撤货

撤货时协议按凭证上的**历史进货数量比例**返还商品本身，**与当下价格无关**；期间累积的手续费、福利等作为净值增量额外结算。详见 [撤资](./Devest) 与 [三重防护](./LP)。

## 供货商的三份收益

| 收益来源 | 何时到账 | 计价货币 |
|:--|:--|:--|
| ① 本金 | 撤货时按历史数量返还 | 你补的那种商品 |
| ② 交易手续费分佣 | 撤货时或 `collectCommission` 领取 | 对应货架商品 |
| ③ TTS 挖矿 | 撤货时 `unstake` 铸造 | TTS |
