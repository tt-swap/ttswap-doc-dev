# 三重防护与零无常损失

供货商最关心两件事：**本金会不会被价格波动吃掉**，以及**恶意卖压会不会掏空货架**。TTSWAP 用「库存安全带 + 历史数量返还 + 多层缓冲」一起回答这两个问题。

## 一、货架库存安全带（safeLine）

每条货架的可交易深度被 `safeLine` **上下界**框在健康区间内。默认 0 表示不额外收紧；管理员可为长尾货架设更紧区间。

### 没有安全带会发生什么

若来者不拒：骗子可上架空气币、大量卖给商场、套走 USDT / ETH——经典的「一般商品反向抽干」。安全带就是为阻断这类路径。

### 合约如何检查

大额 swap 分片计算结束后：

| 方向 | 检查 | 失败 |
|:--|:--|:--|
| **卖入侧**（把商品卖给货架） | 库存 $Q$ 不得超过上界 | `TTSwapError(55)` |
| **买出侧**（从货架买走） | 库存 $Q$ 不得低于下界 | `TTSwapError(56)` |

上下界由 `safeLine` 与基准库存（`I` + 虚拟量）按比例算出。

### 带来的行为规律

1. 大额卖压触及上界会被拒收，须等买盘或撤货释放空间；
2. 新上架商品需要真实需求消化库存，才能继续承受卖单；
3. 外部价格暴跌时，砸盘无法一口气掏空货架——后续订单撞墙，套利与 LP 撤货逐步修复价格。

### 一般商品 vs 硬通货

| 场景 | 一般商品 | 硬通货 |
|:--|:--|:--|
| 大额卖压撞墙 | **会**（触及上界） | 区间通常更宽，由管理员配置 |
| 单边补货计价 | 统一按池内价 | 同左 |
| 可作定价锚 | 可以但不权威 | 社区提权后更权威 |

一般商品在「卖出上限」上更严格，用于保护供货商不被恶意商品稀释。硬通货特权对应社区 II 类提案审批后的身份信用。

## 二、按历史数量返还（协议级零 IL）

传统 Uniswap 式 AMM：存入 1 ETH + 2000 USDT，价格变动后再撤出，两侧数量会变形——**价值可能涨了，ETH 数量却少了**。

TTSWAP：

- 凭证记录的是**历史进货数量**；
- 撤货按该历史比例返还**同种商品**；
- 与当下价格脱钩，手续费等收益另计净值增量。

这是「零无常损失」在协议层的直接实现，而不是事后补贴口头承诺。详见 [撤资](./Devest)。

## 三、三层防御：抵御极端风险

除安全线与历史返还外，还有三层缓冲：

| 层级 | 机制 | 作用 |
|:--|:--|:--|
| **第一道：协议级价值锚定** | 凭证记历史数量，撤货按比例返还 | 代码层保证数量预期 |
| **第二道：品牌方劣后缓冲** | 发行方初始流动性在极端行情下优先承担缺口 | 资金层保险垫 |
| **第三道：TTS 治理补偿** | 极端不可覆盖损失，可由 DAO 决议启动补偿 | 治理层兜底 |

**直觉**：个人供货商不是独自裸奔承担 IL；手续费复利 + 缓冲机制通常把风险收敛到可接受水平。
