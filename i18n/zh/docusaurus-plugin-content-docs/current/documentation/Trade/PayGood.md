# 支付（payGood 与 X402）

`payGood` 是 **Exact-Out** 下单：你固定「要拿到多少」，协议反推「需要付多少」，并校验是否超过你设的愿付上限。它同时覆盖**异币兑换**与**同币精确转账**，并与 **X402 商家模式**深度结合。

## 一、payGood：我要精确拿回 Y

### 场景

> 「给我恰好 10 个面包，我愿意付不超过 50 USDT。」

### 执行步骤

1. 反推：拿到固定输出需要多少购买力 $\Delta V$；
2. 再反推：凑齐 $\Delta V$ 需要付多少输入商品；
3. 若愿付超过上限则回滚；
4. 扣款并转出**恰好**指定数量的目标商品。

### 关键字段

| 字段 | 含义 | 示例 |
|:--|:--|:--|
| `amount1` | 精确想拿到的数量（固定） | 10 个面包 |
| `amount0` | 愿付上限 | 50 USDT |
| `external_info.amount0` | 业务信息（如订单号） | 可选 |
| `external_info.amount1` | deadline | 强烈建议非零 |

## 二、同币种快路径：商家收款专用

常见需求：顾客用 USDT 付给商家 **恰好 10 USDT**——这不是兑换，是纯转账。

当 `_goodid1 == _goodid2` 时，协议：

- **完全跳过 AMM**；
- 直接从付款方扣款 → 打入收款方；
- 只扣固定 **执行费 `executeFee`**（合约常量 $5 \times 10^{10}$，按 USDT 6 位精度约 **0.05 USDT**）；
- 无滑点、无定价不确定性。

对比：在仅有 pair 的 DEX 上，同币收款往往要绕 swap 或另接托管；TTSWAP 原生一步到位。

## 三、商家只认收款币，顾客可用任意币付款

`payGood` 把「兑换 + 精确到账」收进同一次调用：

1. **商家**：在订单里写死想收的币种（`_goodid2`）与精确金额；
2. **顾客**：用钱包里任意已上架商品作为 `_goodid1` 付款；
3. **协议**：内部按 Exact-Out 反推应付数量，中央收银台完成兑换并打到商家账户；
4. **滑点保护**：顾客设的愿付上限超限则 revert。

对商家的好处：营收口径统一、覆盖全场持币用户、无需自建兑换路由。

若顾客恰好持有商家要的币，则走上文**同币快路径**。

## 四、X402 商家模式：顾客只签名，商家代上链

### 问题

普通链上支付要求顾客自备 Gas、连钱包发交易——对未接触加密的用户极不友好。

### 解法

> **顾客只签订单不上链；商家（Executor）代付 Gas 送上链，赚固定执行费。**

| 角色 | 做什么 |
|:--|:--|
| **顾客（Trader）** | EIP-712 签「买什么 / 付多少」，不花 Gas |
| **商家（Executor）** | 验签后上链执行，支付 Gas |
| **商场（TTSWAP）** | 执行订单，自动扣 `executeFee` 给商家 |

买单 / 付款单字段含：顾客地址、推荐人（可选）、商品 id、数量、data、deadline / nonce 等。合约先 `ecrecover` 验签，篡改即失败；`nonce` 防重放；顾客可 `cancelNonce()` 作废未上链签名。

### 商家不会做恶？

订单内容由顾客签名绑定。商家只能原样提交，无法改金额、收款人或商品；过期或作废的签名无法兑付。

## 五、小单实时签名 / 大单链上结算

同一张 EIP-712 签名，既可「立刻有效」，也可「稍后批量上链」。商家可按金额分档（阈值 `T` 自定）：

| 档位 | 做法 | 体验 |
|:--|:--|:--|
| **小单 ≤ T** | 本地验签 → 立刻履约；签名入队，稍后 `multicall` 批量上链 | ~1 秒放行，不等区块 |
| **大单 > T** | 先上链确认再履约 | 等链上确认 |

小单存在「上链前资金被转走」的敞口，但被金额天花板 `T`、`deadline`、可审计的 `cancelNonce` 收敛。极度风控可将 `T=0`（全部等上链）。

典型咖啡馆场景：扫码签名 → POS 本地验签约 100ms → 递咖啡 → 下班前批量上链，gas 与 `executeFee` 摊薄。

## 六、场景速查

| 场景 | 推荐路径 |
|:--|:--|
| 恰好买 N 件异币商品 | `payGood` 异币 |
| 商家收恰好 N USDT（顾客也付 USDT） | 同币快路径 |
| 商家收 USDT，顾客付 ETH / 长尾币 | `payGood` 异币 + Exact-Out |
| 顾客无 ETH Gas | X402 + 商家代上链 |
| 面对面小额秒付 | 小单实时签名 + 批量结算 |
