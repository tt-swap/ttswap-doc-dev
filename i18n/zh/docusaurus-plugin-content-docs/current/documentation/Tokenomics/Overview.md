# 代币经济概览

> **TTS = 这间商场的虚拟股权 + 投票权 + 市值驱动的解锁凭证。**

与许多「只投票、与使用脱钩」的治理币不同，TTS 同时承担激励、治理与长期绑定三重角色。

## 基本属性

| 项目 | 内容 |
|:--|:--|
| **名称 / 符号** | TTSwap Token / **TTS** |
| **精度** | 12 位小数 |
| **最大供应量** | **2 亿枚** |
| **通胀** | 约 50 年线性释放，主要分给供货商（LP 挖矿） |
| **通缩** | 商场社区金库利润 **100%** 回购 TTS 并销毁 |

## 供货即挖矿

每次在**承诺型（`isPromised`）**货架上调用 `investGood`，协议把本批货的贡献价值记为 TTS 算力。

每 **86,400 秒（1 天）**自动结算增发：

```text
每日增发量 = (2亿 - 当前流通量) / 18250 × chainRatio / 10000
（结果低于 1 TTS 时按 1 TTS 保底）
```

直觉：

- 剩余可发行量越少，每日增发越少；
- `chainRatio` 按链上交易占比在多链间分配；
- 约 50 年线性释放完毕；
- 算力在补货时记账，收益通常在撤货 `unstake` 时铸造到账——无需单独 `claim`。

开货架（`initGood`）本身**不记** TTS 算力。详见 [投资](../Invest&Devest/Invest) 与 [撤资](../Invest&Devest/Devest)。

## 4C 初始分配

初始约 **4500 万枚** TTS（`left_share`）预留给四类贡献者，即 **4C 模型**：创始人、合伙人、价值贡献、资本贡献。设计刻意让「做事的人」占比最高。详见 [4C 代币分配](./4C%20Allocation)。

## 翻倍解锁

4C 份额**全部锁定**。只有当 TTS 相对 USDT 的价格达到设定阈值，才能解锁一部分；每次解锁后阈值**翻倍**。价格不涨，代币就一直锁住——抗砸盘的核心设计。详见 [价格翻倍解锁](./Price-doubling%20Unlock)。

## 公售（阶梯定价 + 硬顶）

| 阶段 | 已募资 USDT | 兑换比例 |
|:--:|:--:|:--:|
| Tier 1 | ≤ 87,500 | 1 USDT = **25 TTS** |
| Tier 2 | 87,500 – 162,500 | 1 USDT = **20 TTS** |
| Tier 3 | 162,500 – 250,000 | 1 USDT = **16 TTS** |

- 硬顶 **250,000 USDT**，超过直接回滚；
- 进度链上可查；资金由 Token Admin 经 `withdrawPublicSell` 按社区预算使用。

## 离线签名批量分配

大规模空投 / 合作方结算可用 EIP-712 离线签分配单（`permitShare`），受签方自行上链领取：批量、异步、签名侧零 Gas，链上事件可审计。

## 通胀 vs 通缩：双引擎

| 引擎 | 方向 | 机制 |
|:--|:--|:--|
| **通胀** | 发行 | 每日增发给活跃 LP |
| **通缩** | 销毁 | 社区金库利润二级市场回购并销毁 |

长期动态大致为：早期通胀激励挖矿 → 成长期交易放大、通缩占优 → 成熟期稀缺性上升。目标是避免「只增发不回收」导致的持续稀释。
