# 专用名词

TTSWAP 用「去中心化商场」讲协议。读文档前先记住下列对照，后面章节会反复出现。

## 商场 ↔ 协议

| 商场说法 | 协议含义 | 常见代码 / 位置 |
|:--|:--|:--|
| 整间商场 | TTSWAP 协议 | — |
| 中央收银台 | Singleton 市场合约 | `TTSwap_Market_Proxy` |
| 货架 | 每种商品唯一的流动性池 | `goods[goodid]` / `S_GoodState` |
| 商品标识 | `T_GoodKey`（类型 + 合约地址 + 子编号） | `toId()` → `goodid` |
| 供货商 | 流动性提供者（LP） | `investGood` / `disinvestProof` |
| 顾客 | 交易者 | `buyGood` / `payGood` |
| 品牌方 | 货架 Owner（首发开架人） | `goods[goodid].owner` |
| 门店 | 前端 / 聚合器（Gate） | 六方分账中的 gate |
| 商家 | X402 签名中继执行者 | Executor |
| 商场股权凭证 | TTS 代币 | `TTSwap_Token` |

## 货架四要素

每种商品对应**唯一一条货架**，链上主要记这些量：

| 符号 | 商场叫法 | 含义 |
|:--|:--|:--|
| **V** | 市场价值 | 该货架商品在商场内的总价值标价 |
| **Q** | 当前库存 | 货架上现在有多少件 |
| **I** | 累计进货 | 供货商历史上累计放进来的数量 |
| **S** | 总供货份数 | 所有供货商持有的货权总份额 |
| **R** | 总虚拟数量 | 虚拟陈列等不可直接当成交库存的部分 |

**规则**：同一种商品全商场只有一条货架，不可重复开。

## 商品等级

| 等级 | 说明 |
|:--|:--|
| **一般商品（Normal Good）** | 新上架默认等级；受 **安全线（safeLine）** 约束，防恶意卖压抽干硬通货 |
| **硬通货（Value Good）** | 由 CEO（Market Admin）按社区决议提权；可作定价锚，`safeLine` 通常更宽松（如 USDT / ETH） |

## 供货与凭证

| 术语 | 说明 |
|:--|:--|
| **开新货架 `initGood`** | 第一次为某 Token 上架，自定初始价 $V_0/Q_0$，获得品牌方身份 |
| **单币补货 `investGood`** | 只带一种商品补货，按池内现价计价 |
| **供货凭证（Proof）** | 绑定「地址 + 货架」的账本条目，非可交易 NFT；同人同架只有一张，多次补货累加 |
| **虚拟放大 / enpower** | 真实进货按倍数记入虚拟陈列深度，提升可服务交易深度 |
| **承诺型 `isPromised`** | 仅此类货架上的补货才记 TTS 挖矿算力 |
| **撤货 `disinvestProof`** | 按凭证**历史进货数量**比例返还，与当下价格无关（协议级零无常损失基础） |
| **撤货切片** | 单次撤货上限，防止巨鲸一次性砸穿深度 |

## 交易与支付

| 术语 | 说明 |
|:--|:--|
| **`buyGood`（Exact-In）** | 指定付出多少，求最少能接受的到手量 |
| **`payGood`（Exact-Out）** | 指定要拿到多少，设愿付上限 |
| **同币快路径** | 付与收为同一种商品时跳过 AMM，只扣固定执行费 |
| **执行费 `executeFee`** | 约 **0.05 USDT**（常量 $5\times10^{10}$），商家代上链报酬 |
| **X402** | 顾客 EIP-712 签名、商家代付 Gas 上链的支付模式 |
| **安全线 safeLine** | 库存上下界；触界则交易失败，保护货架 |

## 六方分账

每笔利润按货架配置分给六方，**总和必须 = 100%**：

| 角色 | 商场身份 | 典型占比 |
|:--|:--|:--|
| 供货商（LP） | 补货的人 | 50%–80% |
| 品牌方（Operator） | 货架发行方 / Owner | 1%–3% |
| 门店（Gate） | 前端 / 聚合器 | 5%–25% |
| 推荐人（Referral） | 拉新 | 5%–10% |
| 顾客（Customer） | 折扣返佣 | 5%–10% |
| 商场（Platform） | 社区金库 | 2%–8% |

领取入口：`collectCommission`。

## TTS 与治理（速记）

| 术语 | 说明 |
|:--|:--|
| **TTS** | 治理 / 激励代币，总量 **2 亿**，精度 12 |
| **供货即挖矿** | 承诺型货架补货记算力，约 50 年线性日增发 |
| **4C** | 创始人 / 合伙人 / 价值贡献 / 资本贡献 初始锁定分配 |
| **翻倍解锁** | TTS/USDT 价格达标才解锁一档，阈值随解锁次数翻倍 |
| **社区 / CEO / 董事会** | 决策、执行、监督三权分立；合约钥匙按角色映射 |
